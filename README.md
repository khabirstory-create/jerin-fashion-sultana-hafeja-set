# 🛍️ সুলতানা হাফেজা সেট (Sultana Hafeja Set) - ই-কমার্স ল্যান্ডিং পেজ ও অ্যাডমিন প্যানেল

একটি আধুনিক, হাই-কনভার্সন ই-কমার্স ল্যান্ডিং পেজ এবং ফুল-ফিচারড অ্যাডমিন ড্যাশবোর্ড। এটি কাস্টমারের অর্ডার স্বয়ংক্রিয়ভাবে গুগল শিটে সেভ করে এবং গিটহাব ও Netlify এর মাধ্যমে সহজেই লাইভ রান করা যায়।

---

## 🌟 প্রধান ফিচারসমূহ

1. **প্রোডাক্ট ল্যান্ডিং পেজ (`/` এবং `/sultana-hafeja-set/`)**:
   - প্রিমিয়াম রেস্পন্সিভ ডিজাইন ও ইমেজ গ্যালারি অটো-স্লাইডার।
   - সাইজ সিলেকশন (৫০, ৫২, ৫৪, ৫৬, ৫৮) ও ভ্যারিয়েন্ট সিলেকশন (ফুল সুলতানা সেট / শুধু হিজাব ও নিকাব)।
   - লাইভ স্টক কাউন্টার বার ও গ্রাহক রিভিউ রেটিং।
   - ২৪ ঘণ্টার অটো-রিসেট কাউন্টডাউন টাইমার।
   - সরাসরি গুগল শিটে অর্ডার সাবমিশন ও ধন্যবাদ পপআপ কনফেটি অ্যানিমেশন।
   - হোয়াটসঅ্যাপ ও কল বাটন।

2. **অ্যাডমিন ড্যাশবোর্ড (`/admin/`)**:
   - লাইভ ডিজিটাল ঘড়ি, গুগল শিট সিঙ্ক বাটন ও নতুন অর্ডার বাটন।
   - অর্ডার সার্চ (নাম, ফোন, অর্ডার আইডি), স্ট্যাটাস ফিল্টার ও সোর্স ফিল্টার।
   - কাস্টমার ফোন নম্বরের পাশে **Check** বাটন দিয়ে কুরিয়ার হিস্ট্রি ও ফ্রড চেক।
   - অর্ডার স্ট্যাটাস পরিবর্তন (`Processing`, `Completed`, `Phone Confirm`, `In Courier`, `Cancelled`, `Returned`)।
   - ইনভয়েস প্রিন্ট / মেমো ভিউ।
   - CSV ফাইল এক্সপোর্ট ও টেস্ট ডাটা ডিলিট সুবিধা।
   - ড্যাশবোর্ড অ্যানালিটিক্স ও সেটিংস প্যানেল।

## 📊 ধাপ ১: গুগল শিট (Google Sheet) সেটআপ নির্দেশিকা

1. প্রথমে [Google Sheets](https://sheets.new) এ গিয়ে একটি নতুন স্প্রেডশিট তৈরি করুন।
2. ওপরের মেনু থেকে **Extensions** > **Apps Script** এ ক্লিক করুন।
3. স্ক্রিপ্ট এডিটরের বিদ্যমান কোড মুছে দিয়ে এই প্রজেক্টের `GoogleAppsScript.js` ফাইলের সম্পূর্ণ কোড পেস্ট করুন।
4. ওপরের নীল রঙের **Deploy** বাটনে ক্লিক করুন > **New deployment** সিলেক্ট করুন।
5. গিয়ার আইকনে ক্লিক করে **Web app** সিলেক্ট করুন:
   - **Description**: `Order Sync API`
   - **Execute as**: `Me` (আপনার জিমেইল)
   - **Who has access**: `Anyone` (যেকোনো ব্যক্তি)
6. **Deploy** বাটনে ক্লিক করুন এবং পারমিশন চাইলে এক্সেস অ্যাপ্রুভ করুন।
7. পাওয়া **Web App URL** টি কপি করুন।
8. আপনার সাইটের `/admin/` এ গিয়ে **Settings** ট্যাবে এই URL টি পেস্ট করে **সেটিংস সেভ করুন** বাটনে ক্লিক করুন।

## 🐙 ধাপ ২: গিটহাব (GitHub) এ পুশ করার নিয়ম

আপনার প্রজেক্ট ফোল্ডারে টার্মিনাল বা কমান্ড প্রম্পট খুলে নিচের কমান্ডগুলো রান করুন:

```bash
# ১. গিট ইনিশিয়ালাইজ করুন
git init

# ২. সব ফাইল যুক্ত করুন
git add .

# ৩. প্রথম কমিট করুন
git commit -m "Initial commit - Sultana Hafeja landing page & admin panel"

# ৪. মেইন ব্রাঞ্চ সিলেক্ট করুন
git branch -M main

# ৫. আপনার গিটহাব রিপোজিটরির লিংক যুক্ত করুন (আপনার রিপোজিটরির URL দিন)
git remote add origin https://github.com/your-username/sultana-hafeja-set.git

# ৬. গিটহাবে পুশ করুন
git push -u origin main
```

## 🚀 ধাপ ৩: Netlify তে ডিপ্লয় (Deploy) করার নিয়ম

### পদ্ধতি ১: GitHub কানেক্ট করে (সবচেয়ে সহজ)
1. [Netlify](https://app.netlify.com/) এ লগইন করুন।
2. **Add new site** > **Import an existing project** সিলেক্ট করুন।
3. **GitHub** সিলেক্ট করে আপনার `sultana-hafeja-set` রিপোজিটরিটি বেছে নিন।
4. **Deploy site** বাটনে ক্লিক করলেই কয়েক সেকেন্ডে আপনার ওয়েবসাইট লাইভ হয়ে যাবে!

### পদ্ধতি ২: Drag and Drop করে
1. এই পুরো ফোল্ডারটি Netlify এর ড্যাশবোর্ডে টেনে নিয়ে ছেড়ে (Drag & Drop) দিলেই সাইট সাথে সাথে রান হয়ে যাবে।
